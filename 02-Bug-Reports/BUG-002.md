# BUG-002 - El carrito de compras muestra un precio incorrecto del producto

**Severidad:** Media

## Información general

- **Módulo:** Carrito de compras.
- **Tipo:** Error funcional.
- **Severidad:** Media.
- **Prioridad:** Alta (provisional).
- **Estado:** Abierto.

## Precondiciones

- El usuario debe tener acceso al sitio web de comercio electrónico.
- Debe haber un producto disponible con un precio de $25.000.

## Pasos para reproducir el error

1. Ingresar al catálogo de productos.
2. Seleccionar un producto con un precio de $25.000.
3. Agregar una unidad al carrito de compras.
4. Abrir el carrito de compras.

## Resultado esperado

El carrito de compras debería mostrar el precio correcto del producto: $25.000.

## Resultado obtenido

El carrito de compras muestra un precio incorrecto: $20.000.

## Evidencia

Captura de pantalla que muestre el precio del producto y el total incorrecto del carrito.

## Entorno de prueba

- **Entorno:** Ambiente de pruebas (Test), a definir.
