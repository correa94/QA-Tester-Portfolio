# BUG-001 - El inicio de sesión permite acceder con una contraseña incorrecta

## Información general

- **Módulo:** Inicio de sesión / Autenticación
- **Tipo:** Seguridad / Funcional
- **Severidad:** Alta (provisional)
- **Prioridad:** Alta
- **Estado:** Abierto

## Descripción

La aplicación permite a los usuarios acceder a sus cuentas utilizando una contraseña incorrecta.

## Precondiciones

Debe existir un usuario registrado en el sistema.

## Pasos para reproducir el error

1. Ingresar a la página de inicio de sesión.
2. Introducir una dirección de correo electrónico registrada.
3. Introducir una contraseña incorrecta.
4. Hacer clic en el botón «Iniciar sesión».

## Resultado esperado

La aplicación debería rechazar el intento de inicio de sesión y mostrar un mensaje de error.

## Resultado obtenido

La aplicación permite acceder a la cuenta utilizando una contraseña incorrecta.
