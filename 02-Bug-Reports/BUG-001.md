# BUG-001 - Login allows access with incorrect password

## General Information

- **Module:** Login / Authentication
- **Type:** Security / Functional
- **Severity:** High (provisional)
- **Priority:** High
- **Status:** Open

## Description

The application allows users to access their accounts using an incorrect password.

## Preconditions

A registered user exists in the system.

## Steps to Reproduce

1. Navigate to the login page.
2. Enter a registered email address.
3. Enter an incorrect password.
4. Click on the "Login" button.

## Expected Result

The application should reject the login attempt and display an error message.

## Actual Result

The application allows access using an incorrect password.
